# flint2-telegram-bot

Лёгкий Telegram-бот для роутеров **GL.iNet Flint 2 (GL-MT6000)** и других устройств на **OpenWrt / GL.iNet 4.x**.
Работает прямо на роутере, написан на `sh` + `curl` + `jq` (и немного Lua), занимает около **120 КБ** и почти не нагружает процессор.
Умеет работать в паре с **Home Assistant**: отопление, «никого нет дома», датчики, графики, календарь.

> English: a tiny shell-only Telegram bot that runs on a GL.iNet/OpenWrt router. It sends alerts
> (new devices, VPN events, internet outages, DNS anomalies, hardware warnings) and answers commands
> (`/status`, `/clients`, `/block`, `/wake`, `/speedtest`, `/reboot`, ...). Optional Home Assistant link:
> heating control, away mode, sensors, charts, calendar, morning brief. Docs are in Russian.

## Возможности

**Уведомления**
- Роутер загрузился (со статусом).
- **Новое устройство в сети**: имя, производитель по MAC, Wi-Fi (диапазон, сеть, сигнал) или кабель, кнопки **«Знаю» / «Заблокировать»**.
- **WireGuard**: клиент подключился или отключился.
- **Интернет** пропал и вернулся (с длительностью).
- Перебор паролей по SSH.
- **Слежение за устройствами**: «iPhone пришёл домой / ушёл», «принтер пропал на час».
- **Мониторинг сайтов и сервисов** (HTTP и TCP) с уведомлением о падении и восстановлении.
- **Скорость интернета**: ночной замер, история, сообщение при просадке.
- **Недельный дайджест**: DNS, новые устройства, скорость, трафик, перебои.
- **Проверка портов** нового устройства (камеры, telnet и т.п.).
- Перегрев, нехватка памяти, заполнение диска.
- **Утренняя сводка в 07:45**: погода по часам и что надеть, календарь на сегодня, температура дома, что было ночью.
- Тревоги приходят **со звуком**, информационные сообщения — **без звука**.

**С Home Assistant** (необязательно, см. [docs/HOME-ASSISTANT.md](docs/HOME-ASSISTANT.md))
- «Дома никого»: HA решает по Wi-Fi и входной двери, спрашивает «выключить свет?», охраняет, пока дом пуст.
- Режим **«Ухожу»** одной кнопкой: всё выключить, отопление в эконом, охрана через 5 минут.
- **Отопление**: HA держит температуру по комнатным датчикам, день/ночь/эконом, кнопки ± в боте.
- Датчики и батареи, графики температуры и влажности, журнал событий дома, календарь.

**Команды** (ответ мгновенный, бот отвечает только вашему `chat_id`)

| Команда | Действие |
|---|---|
| `/menu` | меню по разделам: Дом, Отопление, Журнал, Сеть, Устройства, Сервис |
| `/status` | аптайм, нагрузка, память, температура, WAN IP, число устройств |
| `/clients` | кто в сети (с именами, помечает заблокированных) |
| `/vpn` | кто подключён по WireGuard |
| `/report` | DNS за 24 часа: запросы, блокировки, топы |
| `/speedtest` | скорость и пинг (через Cloudflare) |
| `/block`, `/unblock`, `/pause` | блокировка устройств, в том числе на время (по IP, MAC или имени) |
| `/who <устройство>` | какие сайты открывает устройство |
| `/wake <устройство>` | Wake-on-LAN |
| `/name <устройство> <имя>` | задать своё имя устройству |
| `/vpn add <Имя>` | новый VPN-пользователь: QR-код и конфиг в чат (удаляются через 2 минуты) |
| `/watch`, `/home` | слежение за устройствами, кто дома |
| `/scan <устройство>` | открытые порты устройства |
| `/site add`, `/sites` | мониторинг сайтов |
| `/speedhist` | история скорости |
| `/backup`, `/digest` | зашифрованный бэкап конфигурации, итоги недели |
| `/reboot` | перезагрузка с кнопкой подтверждения |
| `/log [дом\|сеть\|люди]` | журнал событий за сутки с фильтрами |
| `/heat` | отопление (HA): режим, температуры, день/ночь ± |
| `/sensors`, `/graph` | датчики и батареи; графики температуры и влажности (HA) |
| `/cal` | календарь на сегодня и завтра (HA) |

Подробнее: [docs/COMMANDS.md](docs/COMMANDS.md).

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и сохраните токен.
2. Настройте SSH-доступ к роутеру по ключу: `ssh-copy-id root@192.168.8.1`.
3. На компьютере выполните:

```sh
git clone <адрес этого репозитория>
cd flint2-telegram-bot
./install.sh root@192.168.8.1
```

Скрипт скопирует файлы, спросит токен, сам определит ваш `chat_id` и запустит бота.
Подробная инструкция и ручная установка: [docs/INSTALL.md](docs/INSTALL.md).

## Обновление

```sh
git pull && ./update.sh
```

## Управление

На роутере (по SSH):

```
tgbot-ctl status           # что работает
tgbot-ctl off              # полностью выключить (остановка, без автозапуска)
tgbot-ctl on               # включить
tgbot-ctl remove [--purge] # удалить бота (--purge: вместе с токеном и данными)
```

## Требования

- GL.iNet Flint 2 (GL-MT6000) с прошивкой 4.x или другой роутер на OpenWrt 21.02+ (часть функций, например блокировка через `gl_block` и Wi-Fi-имена интерфейсов `ra0/rax0`, специфична для GL.iNet / MediaTek, см. ARCHITECTURE).
- На роутере: `curl`, `jq`, `lua`, `openssl`, cron (на GL.iNet 4.x есть из коробки); для `/vpn add` пакет `qrencode` (установщик ставит сам).
- Для отчётов и аномалий: AdGuard Home с включённым журналом запросов в файл.
