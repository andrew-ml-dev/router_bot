# Команды и уведомления

Устройство в командах можно указывать по **IP**, **MAC** или **части имени** (имя из DHCP или заданное через `/name`).

## Команды

| Команда | Описание |
|---|---|
| `/help` | список команд |
| `/status` | аптайм, нагрузка, память, температура, WAN IP, число устройств в сети |
| `/clients` | активные устройства: IP, имя, MAC; заблокированные помечены `[ЗАБЛОКИРОВАНО]` |
| `/vpn` | пиры WireGuard: онлайн, «был N мин назад» или «не подключался» |
| `/report` | DNS за 24 часа: число запросов, заблокировано (%), топ заблокированных доменов, топ устройств |
| `/speedtest` | загрузка, отдача, пинг (Cloudflare, около 20 секунд) |
| `/block <устройство>` | заблокировать (интернет и доступ между сетями) |
| `/unblock <устройство>` | разблокировать |
| `/blocked` | список заблокированных |
| `/wake <устройство>` | отправить Wake-on-LAN |
| `/name <устройство> <имя>` | задать своё имя (сохраняется в `/etc/tgbot.names`) |
| `/reboot` | запросить перезагрузку (с кнопками «Да» / «Отмена») |

Примеры:

```
/block iphone
/block 192.168.8.150
/name aa:bb:cc:dd:ee:ff Телевизор
/wake macbook
```

Бот отвечает **только** чату из `CHAT_ID`; сообщения от других игнорируются.

## Уведомления

| Событие | Условие |
|---|---|
| Роутер загрузился | при первом запуске скрипта после загрузки |
| Новое устройство | MAC, которого нет в `/etc/tgbot.known`. Кнопки **Знаю** / **Заблокировать** |
| VPN | пир WireGuard стал онлайн / офлайн (порог: последний handshake < 240 с) |
| Интернет | вернулся после пропажи длиннее 2 минут (сообщение приходит после восстановления) |
| Перебор SSH | 3 и больше неудачных входов за минуту |
| Всплеск DNS | устройство сделало ≥ 500 запросов за 10 минут (ночью 01:00–06:00 ≥ 200) |
| Много блокировок | устройство получило ≥ 150 заблокированных запросов за 10 минут |
| Температура | процессор ≥ 75 °C |
| Память | доступно < 80 МБ |
| Диск | `/overlay` занят ≥ 90% |
| Утренний отчёт | ежедневно в 09:00: статус, VPN, DNS |

Одинаковые тревоги (всплеск по устройству, железо) повторяются не чаще раза в час.

Пороги заданы переменными в начале соответствующих блоков `router/usr/bin/tgbot.sh`
(`QMAX_DAY`, `QMAX_NIGHT`, `BLOCKED_MAX`, `TEMP_MAX`, `MEM_MIN_MB`, `DISK_MAX`).

## Что видно в уведомлении о новом устройстве

```
Новое устройство в сети
Имя: Pixel-9
Производитель: Google, Inc.
Подключение: Wi-Fi 5 ГГц (ИмяСети5G), сигнал -57 dBm
IP: 192.168.8.142
MAC: aa:bb:cc:dd:ee:ff
[Знаю] [Заблокировать]
```

- Производитель определяется по первым 3 байтам MAC через `api.macvendors.com` (отправляется только префикс).
- Современные телефоны используют случайный MAC (второй символ 2, 6, A или E): тогда пишется «приватный MAC».
- Устройства, уже видимые при первом запуске, считаются известными и не вызывают уведомлений.
