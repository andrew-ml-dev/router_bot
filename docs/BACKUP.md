# Бэкап конфигурации

Бот умеет присылать в Telegram **зашифрованный** архив настроек роутера: каждое воскресенье в 03:00 и по команде `/backup`.

## Включение

Бэкап **выключен**, пока не задан пароль шифрования. На роутере откройте `/etc/tgbot.conf` и добавьте строку:

```
BACKUP_PASS=длинная_случайная_фраза
```

Например, сгенерировать: `head -c 24 /dev/urandom | base64`.

> **Запомните или сохраните пароль в менеджере паролей.** Он нужен для расшифровки. Если роутер умрёт, пароль на нём вам уже не поможет.

Проверка: напишите боту `/backup`. Придёт файл `router-backup-ГГГГММДД.tar.gz.enc`.

## Что внутри и почему шифруется

`sysupgrade -b` собирает все настройки: Wi-Fi (с паролями), WireGuard (**приватные ключи**), список блокировок, настройки AdGuard и сам бот (включая токен).
Такой файл нельзя хранить открыто, а Telegram не является сквозным шифрованием для ботов, поэтому архив шифруется **до отправки**:
AES-256-CBC, ключ из пароля через PBKDF2 (100 000 итераций), соль случайная. Без `BACKUP_PASS` бот отказывается его отправлять.

## Расшифровка

На любом компьютере с OpenSSL (macOS, Linux):

```sh
openssl enc -d -aes-256-cbc -pbkdf2 -iter 100000 \
    -in router-backup-20261108.tar.gz.enc -out router-backup.tar.gz
# спросит пароль (BACKUP_PASS); при неверном пароле: "bad decrypt"
tar tzf router-backup.tar.gz | head       # посмотреть содержимое
```

## Восстановление на роутер

```sh
scp -O router-backup.tar.gz root@192.168.8.1:/tmp/
ssh root@192.168.8.1 'sysupgrade -r /tmp/router-backup.tar.gz && reboot'
```

Установленные пакеты (`qrencode`) в архив не входят: после восстановления на чистую прошивку выполните
`opkg update && opkg install qrencode`.

## Сохранение бота при обновлении прошивки

Установщик добавляет файлы бота и его данные в `/etc/sysupgrade.conf`. При обновлении прошивки **с сохранением настроек** бот останется на месте.
Пакет `qrencode` придётся поставить заново (`opkg install qrencode`).
